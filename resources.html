FREE LEARNING RESOURCES

Every great developer
starts somewhere.

You don't need expensive classes or software to start learning to code. These are some of the tools I'm exploring on my journey—from typing and coding basics to creating games and publishing websites. I hope they help you start yours, too!

— AJ Florido

01

START HERE

Build your foundation

⌨️Free lessons

Typing.com

Typing is a developer's everyday skill. Practicing accuracy and speed means less time hunting for keys and more time turning ideas into code.

Why it matters: Builds confidence with the keyboard.

Explore Typing.com ↗
🧩Free to use

Scratch

Create animations, stories and games by snapping coding blocks together. It's a friendly way to experiment with loops, events and logic.

Why it matters: Learn how programs think before worrying about syntax.

Explore Scratch ↗
02

LEVEL UP

Learn real programming

💻Free tools available

Pickcode

Practice writing code in a browser and explore programming languages. Try a small challenge, make a mistake, and learn by fixing it.

Why it matters: Turns coding lessons into hands-on practice.

Explore Pickcode ↗
📚Free learning

Khan Academy

Follow guided lessons and practice programming concepts step by step. Learning the 'why' behind code makes building your own projects easier.

Why it matters: Develops problem-solving and programming fundamentals.

Explore Khan Academy ↗
