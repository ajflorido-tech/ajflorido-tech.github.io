FREE GITHUB PAGES PUBLISHING
1. Sign into your parent-managed GitHub account.
2. If your GitHub username is ajflorido, create a PUBLIC repository named ajflorido.github.io.
   If your username differs, create a repository named YOURUSERNAME.github.io instead.
3. Select Add file > Upload files, and upload the four website files:
   index.html, games.html, projects.html, style.css, script.js
   (README.txt is optional). Upload the files themselves, not the ZIP.
4. Commit changes.
5. In repository Settings > Pages, select Deploy from a branch, main, /(root), Save.
6. Wait a few minutes, then open https://YOURUSERNAME.github.io/

Note: The exact ajflorido.github.io URL requires the GitHub username ajflorido. A repository with that name under another username does not reserve that address.

For privacy, use a parent-managed account and do not publish the child's school, location, personal email or other sensitive information.
